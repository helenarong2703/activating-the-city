# Activating the City

A local review build documenting Helena Rong's Spring 2025 Experience Studio at NYU Shanghai: **Activating the City: Media for the Public Realm**.

## Run locally

```bash
npm install
npm run dev
```

## Checks

```bash
npm test
npm run build
```

## Editorial scope

The site includes the course arc, Panlong Tiandi field context, six student projects, invited guests, and selected readings. Student emails and raw submissions are intentionally excluded. Names and documentary photographs remain subject to instructor approval before publication.
